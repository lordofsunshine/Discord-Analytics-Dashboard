## 🚀 Powerful Analytics for Your Discord Servers

Discord Analytics Dashboard is a comprehensive tool designed to provide deep insights into your Discord server's activity. With an intuitive interface and powerful features, this dashboard helps server owners and administrators make data-driven decisions to improve engagement and community management.

### ✨ Key Features

- **Real-time Analytics**: Get up-to-date information about server activity, member growth, and engagement metrics.
- **Multi-server Support**: Manage and analyze multiple Discord servers from a single dashboard.
- **Role Management**: Easily view, manage, and delete roles directly from the dashboard.
- **Customizable Date Ranges**: Analyze data for specific time periods with our flexible date range selector.
- **Beautiful Visualizations**: Understand your data at a glance with our stylish interactive charts and graphs.
- **User-friendly Interface**: Navigate your server data easily with our intuitive design.

### 📊 Comprehensive Analytics

- Channel Activity

### 📄 Pages

1. **Home Page**: Welcome screen with login option and project overview.
2. **Server List**: View all Discord servers you can manage.
3. **Management Panel**: Detailed analytics and role management for each server.
4. **404 Page**: Custom error page for better user experience.

### 🛠 Setup

1. Clone the repository
2. Install dependencies with `npm install`
3. Configure `.env` file with the following variables:

```plaintext
DISCORD_CLIENT_ID=your_client_id
DISCORD_CLIENT_SECRET=your_client_secret
DISCORD_BOT_TOKEN=your_bot_token
REDIRECT_URI=your_redirect_uri
```

4. Start the server with `npm start`

### 🔐 Security

This project uses secure authentication methods and stores sensitive information in environment variables to ensure the security of your Discord server data.
